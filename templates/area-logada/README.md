# Área logada

Código da área logada (área do cliente autenticado).

Este repositório é trabalhado principalmente por agentes de IA orquestrados pelo
[Symphony](../../README.md): cada issue do projeto no Linear vira uma branch e um Pull Request aqui.
Humanos revisam e fazem o merge dos PRs.

## Como contribuir

1. Crie/priorize issues no projeto do Linear (estado **Todo**).
2. O Symphony pega a issue, o agente implementa e abre um PR.
3. A issue vai para **In Review**: revise o PR, peça ajustes comentando na issue
   (e voltando-a para **Todo**) ou faça o merge e mova a issue para **Done**.
